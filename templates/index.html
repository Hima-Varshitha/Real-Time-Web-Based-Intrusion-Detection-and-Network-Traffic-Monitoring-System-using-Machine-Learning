System Capabilities

Intrusion detection workflow

The system combines dataset-based traffic replay, machine-learning classification and live logging to demonstrate an end-to-end intrusion detection workflow.

KDD Cup 99 Dataset

Uses labelled KDD Cup 99 network connection records containing 41 traffic features for model training and traffic replay.

Three ML Models

Decision Tree, Logistic Regression and Random Forest independently classify each processed traffic record.

Real-Time Replay

Genuine labelled KDD records are replayed sequentially to simulate a continuously arriving network traffic stream.

Detection Logs

Recent predictions, final classifications, known traffic labels and attack types are presented through a live monitoring console.

Architecture

How the system processes traffic

Each replayed network connection follows the same preprocessing and prediction workflow used by the trained machine-learning pipelines.

01

Traffic Record

A labelled KDD Cup 99 connection record enters the replay stream.

02

Preprocessing

The saved ML pipelines transform categorical and numerical network features.

03

Classification

Decision Tree, Logistic Regression and Random Forest generate predictions.

04

Final Detection

Majority voting produces the final Normal or Attack classification and records it.
